自從上次引入阻擋 bot 快速通關玩家的機制後
bot 的行為早已也有了對應的改變

之前我們為了避免誤擋無辜的玩家
阻擋的機制是依 `玩家為單位`，
一位玩家若在單位時間內出現超過門檻次數的快速通關行為，就將該玩家列入暫時禁制名單
快速通關的判定條件基本是 20秒以內通關

但現在 bot 也應該調整了策略
把它刷關的時間調整到超過 20 秒才通關
並且同一時間多開很多個用戶帳號，所以不會觸發進到暫時禁制名單

這樣同時間會對 server 產生大量的負荷，導致 server 的 scaling policy 啟動
目前在非旺季的情況下，粗估每個月會增加至少超過 $9000 的費用

因此我們想討論調整成更嚴格的阻擋機制的可能
改直接以 ip 來源來做為判斷基準 (而非以玩家為單位)
也就是偵測到特定 ip 有異常行為，當超過門檻條件，會將該 ip 暫時封鎖

當然偵測的方式和門檻條件我們需要再評估，以免過於嚴苛影響到一般正常玩家

我這裡挑了過去幾天的 log 做基本的統計
https://docs.google.com/spreadsheets/d/1VGRdiS57IaPaKzkyklC8YqHXEwne2NSc2L7H4K-lJXA/edit?gid=976957381#gid=976957381

可以觀察到每天都有將近 5000+ 個可疑 ip 在刷關卡
有些 ip 甚至一天會刷破千次的關卡，並且多達超過 200+ 個玩家帳號，明顯不是正常行為
(甚至有付費玩家，也有疑似刷關的行為)

總而言之
基於上述原因和情況，想提出和 BNE 確認我們是不是能再進一步用 ip 的方式去限制 bot
(或者又回到啟用 device check 的討論)






有那種反正不管，就把時間拉長到 40~50 秒的，但反整一整天就一直在刷關卡的
也有一天只刷個幾次，但持續好幾天
