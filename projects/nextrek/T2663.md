# 實作財務報表 markdown 格式下載

在「報表」功能中，增加可以讓使用者下截財務報表為 markdown 格式的功能

報表包括：
- 損益表
- 資產負債表
- 現金流量表

下載功能會將三種報表合併為一個 markdown 檔案，
並在 markdown 檔案前後加上一些說明資訊文字
提供給使用者下載


## 需求

- 在主選單「報表」中，增加「下載財務分析包」的選項，進到報表下載主畫面
- 新增下載財務分析包的主畫面，實作一個表單，讓使用者
  1. 選擇年份
  2. 補統說明文字，填寫企業背景補充說明文字
  3. 選擇是否要將報表資訊去識別化，包括：隱藏公司名稱、隱藏實際年份
- 使用者按下「下載」按鈕後，送出表單，系統會產生一份 markdown 格式的檔案下載至使用者電腦

### 使用者輸入參數

主畫面的表單，將所有參數放在 params[export] 裡
包含以下欄位：

```
export[year]                    # integer
export[description]             # text
export[anonymize_company_name]  # boolean
export[anonymize_year]          # boolean
```

### 報表日期區間

使用者是選擇年份，需判斷是否為當前年份
若是當前年偂， 則報表日期區間為 yyyy/01/01 ~ 當前日期
若為過去年份，則報表日期區間為 yyyy/01/01 ~ yyyy/12/31

### Markdown 檔案內容格式

檔案包含以下內容：


```
# 財務報表彙整

## 公司名稱：{Company}

## 財報年度：{Year}

## 企業背景
{description}

## 損益表 (Income Statement)

{table data here}

## 資產負債表 (Balance Sheet)

{table data here}

## 經營現金流量表 (Cash Flow Statement)

{table data here}

```

- {Company}：若使用者選擇去識別化，則顯示「某某公司」，否則顯示實際公司名稱
- {Year}：若使用者選擇去識別化，則顯示「20XX」，否則顯示實際年份


請參考檔案：@example.md

## 程式碼參考與建議

三項報表已是既有功能，並且已封裝成 Presenter object，僅需增加將三種報表輸出成 markdown 格式並且將內容合併為

- 損益表: Accountings::IncomeStatementPresenter
- 資產負債表 Accountings::BalanceSheetPresenter
- 現金流量表 Accountings::CashFlowStatementPresenter

請將三個 object 實作可以輸出成 markdown 格式的功能，方便後續合併輸出

markdown 輸出格式基本上就是原本 presenter 的 html 格式表格資料
轉換成用純文字呈現，可以使用 ruby 的 gem `Tabulo` 來產生文字表格


## Route and Controller

/reports/packages -> Reports::PackagesController#index, 顯示主畫面
/reports/packages/download -> Reports::PackagesController#download, 依傳入參數產生 markdown 檔案並下載

## 新增 PackagePresenter

實作 Reports::PackagePresenter 來產生最終的 markdown 內容
內容包括：

- 合併三個報表的 markdown 資料
- 加上使用者輸入的資料
- 產生最終的 markdown 內容

## 年份選擇器

這個功能需要一個允許使用者選擇年份的輸入欄位

請設計一個可以重複使用的年份輸入選擇元件
它可以接受一個 rails form builder 物件，以及 input 名稱，並且產生一個年份選擇的下拉選單
年份選項預設是當前年份到 5 年前
並可以接受以下參數來調整年份選項範圍：
  - 指定 range
  - 指定起始年份，預設結束年份為當前年份
  - 指定結束年份，預設起始年份為 5 年前
  - 指定一個相對於當前年份的數字，例如 10 代表從今年起往前推 10 年

請用 StimulusJS 來實作這個元件的互動行為
