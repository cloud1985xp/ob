## 3. 版面配置 (Layout)

### 整體架構
```
┌─────────────────────────────────────────────────────────┐
│                    頂部導航列 (Top Navigation)            │
├────────────┬────────────────────────────────────────────┤
│            │                                            │
│   側邊欄    │              主內容區域                     │
│  (Sidebar) │           (Main Content)                   │
│            │                                            │
│  - 總覽     │   ┌─────────────────────────────────┐     │
│  - 交易  >  │   │      頁面標題 / 麵包屑            │     │
│  - 會計  >  │   ├─────────────────────────────────┤     │
│  - 報表  >  │   │      篩選/操作區                  │     │
│  - 帳戶  >  │   ├─────────────────────────────────┤     │
│  - 設定  >  │   │      主要內容區                   │     │
│  - 通息     │   │      (表格/表單/報表)             │     │
│            │   └─────────────────────────────────┘     │
├────────────┴────────────────────────────────────────────┤
│                       頁尾 (Footer)                      │
└─────────────────────────────────────────────────────────┘
```

### 側邊欄 (Sidebar)
- 寬度: 約 200px
- 背景: 深藍灰色
- 選單項目帶展開/收合功能
- 目前選中項目有左側高亮指示

### 主內容區域
- 左右邊距: 約 24px - 32px
- 卡片間距: 約 16px - 24px

## 4. UI 元件清單 (Component Inventory)

### 4.1 導航元件 (Navigation)

#### 頂部導航列 (Top Navigation Bar)
- **組成**: Logo + 帳本名稱 + 年度選擇器 + 功能按鈕群 (購買/通知/郵件/設定/登出)
- **高度**: 約 56px
- **背景**: 白色

#### 側邊欄導航 (Sidebar Navigation)
- **類型**: 可折疊選單
- **圖示**: 每個選單項目前有圖示
- **展開指示**: 箭頭圖示表示可展開
- **選中狀態**: 左側青綠色指示條

#### Tab 導航 (Tab Navigation)
- **樣式**: 下劃線式
- **使用場景**: 損益表/綜合損益表、對象列表/交易明細
- **選中狀態**: 下方邊框高亮

#### 麵包屑 (Breadcrumb)
- 未明顯使用，頁面標題直接顯示

---

### 4.2 按鈕元件 (Buttons)

#### 主要按鈕 (Primary Button)
- **樣式**: 實心青綠色背景，白色文字
- **使用**: 儲存、搜尋、主要操作
- **範例**: `儲存`、`搜尋`

#### 次要按鈕 (Secondary Button)
- **樣式**: 白色背景，青綠色邊框和文字
- **使用**: 付款、移轉等次要操作
- **範例**: `付款`、`移轉`

#### 輪廓按鈕 (Outline Button)
- **樣式**: 透明背景，細邊框
- **使用**: 篩選、批次操作
- **範例**: `批次分類`、`批次匯入`

#### 圖示按鈕 (Icon Button)
- **樣式**: 僅圖示，無背景或淺色背景
- **使用**: 列表操作 (列印/編輯/複製/刪除)
- **圖示**: 列印、編輯(鉛筆)、複製、刪除(垃圾桶)

#### 切換按鈕群組 (Toggle Button Group)
- **樣式**: 相連的按鈕，選中項目為實心
- **使用**: 收款/付款/移轉 切換、簡明/細項 切換

#### 連結按鈕 (Link Button)
- **樣式**: 純文字連結樣式
- **使用**: 快速篩選、重選

---

### 4.3 表單元件 (Form Components)

#### 文字輸入框 (Text Input)
- **樣式**: 矩形邊框，圓角
- **狀態**: 預設、聚焦、禁用
- **Placeholder**: 淺灰色提示文字

#### 日期選擇器 (Date Picker)
- **樣式**: 文字輸入框 + 日曆圖示
- **格式**: YYYY-MM-DD

#### 下拉選單 (Dropdown/Select)
- **樣式**: 文字輸入框 + 向下箭頭
- **搜尋功能**: 部分下拉選單支援搜尋

#### 搜尋式下拉選單 (Searchable Select)
- **樣式**: 帶搜尋輸入的下拉選單
- **使用**: 收款原因、對象選擇

#### 切換開關 (Toggle Switch)
- **樣式**: 圓角矩形滑動開關
- **使用**: 手續費、營業稅啟用/停用

#### 單選按鈕 (Radio Button)
- **樣式**: 圓形單選按鈕
- **使用**: 簡明/細項 視圖切換

#### 檔案上傳 (File Upload)
- **樣式**: 按鈕 + 上傳圖示
- **文字**: `上傳附件`

#### 標籤輸入 (Tag Input)
- **樣式**: 文字輸入框，支援多標籤

---

### 4.4 數據展示 (Data Display)

#### 數據表格 (Data Table)
- **表頭**: 青綠色背景，白色文字
- **斑馬紋**: 淺灰色交替行
- **操作欄**: 固定在右側
- **欄位類型**: 文字、金額、日期、連結、徽章、操作按鈕

#### 卡片 (Card)
- **樣式**: 白色背景，輕微陰影
- **使用**: 資訊分組、Dashboard 區塊

#### 統計摘要列 (Summary Bar)
- **樣式**: 水平排列的統計數據
- **使用**: 交易明細頁面的收款/付款/差額統計

#### 列表項目 (List Item)
- **樣式**: 水平排列的內容，右側操作圖示
- **使用**: 資金帳戶列表

#### 分類標題 (Category Header)
- **樣式**: 青綠色背景，帶總額
- **使用**: 現金類、銀行存款類等分類

#### 徽章/標籤 (Badge/Tag)
- **樣式**: 圓角矩形，填充色
- **顏色**: 付款(青綠)、收款(綠色)
- **使用**: 交易類型標示

#### 金額顯示 (Amount Display)
- **正數**: 黑色文字
- **負數**: 紅色文字，帶負號
- **格式**: 千分位分隔符

---

### 4.5 回饋元件 (Feedback)

#### 幫助提示 (Help Tooltip)
- **觸發**: 問號圖示 (?)
- **使用**: 表單欄位說明

#### 必填指示 (Required Indicator)
- **樣式**: 紅色星號 (*)
- **位置**: 欄位標籤前

#### 空狀態 (Empty State)
- **文字**: "尚無交易" 等提示文字

#### Intercom 聊天按鈕
- **位置**: 右下角浮動
- **樣式**: 圓形藍色按鈕

---

### 4.6 財務報表專用 (Financial Reports)

#### 階層式表格 (Hierarchical Table)
- **展開/收合**: 三角形圖示
- **縮排**: 子項目向右縮排
- **小計行**: 特殊背景色高亮

#### 年/月份選擇器 (Period Selector)
- **樣式**: 左右箭頭 + 年份/月份顯示
- **使用**: 報表期間選擇

#### 圖表 (Charts)
- **類型**: 水位圖表 (趨勢圖)
- **使用**: 帳戶分析

## 6. 設計建議 (Design Recommendations)

### 6.1 需要改善的地方

1. **一致性**
   - 按鈕樣式在不同頁面間略有差異
   - 表格操作圖示大小不一致
   - 需統一間距規範

2. **無障礙性**
   - 部分顏色對比度可能不足
   - 需要增加更多 aria 標籤
   - 鍵盤導航支援需加強

3. **響應式設計**
   - 目前主要針對桌面版設計
   - 表格在小螢幕需要橫向捲動處理

4. **空狀態處理**
   - 空列表時的視覺引導可以更豐富

### 6.2 建議的設計系統結構

```
Design System/
├── Foundations/
│   ├── Colors (主色、語義色、中性色)
│   ├── Typography (字體、字級、行高)
│   ├── Spacing (間距規範)
│   ├── Shadows (陰影層級)
│   └── Border Radius (圓角規範)
│
├── Components/
│   ├── Buttons (各類按鈕)
│   ├── Forms (輸入元件)
│   ├── Navigation (導航元件)
│   ├── Data Display (數據展示)
│   ├── Feedback (回饋元件)
│   └── Layout (版面元件)
│
├── Patterns/
│   ├── List Page
│   ├── Form Page
│   ├── Report Page
│   ├── Settings Page
│   └── Dashboard
│
└── Templates/
    ├── 交易明細
    ├── 交易建立
    ├── 財務報表
    ├── 帳戶管理
    └── 系統設定
```
