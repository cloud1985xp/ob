# 更新 TranslationSource 的 training data 功能

目前已實作的 training data 功能包括：
- 產生 preview data，位於: /admin/translation_sources/:id/training
- 執行 jenkins traing job，位於: /admin/translation_sources/:id//trigger_training
- Rosetta.Trainings module 

需進行以下修改：

一、產生 data 前需重建 formatted_source_strings (包含 translations)
在實際產生 training data 之前，要先執行 Patterns.process_n1_pattern_formations 重建所有 formatted source string
因為有可能來源的 source_strings / translations 有資料變動，所以實際產生 data 前要重新建立 formatted source strings 等資料

二、產生 data 時需區分是否為一般 or n1 data
在實際(leaf 端) 產生 training data 時需檢查 TranslationSource 的 pattern strategies 是否有 n1 (目前只有有 n1)，來區分產生資料的方式：

- 若是有 n1 pattern：
	- 依目前的方式 -> 重建 n1 pattern formations -> 用 formatted source string 去 expand 產生 training data
- 若不具有 n1 pattern：
	- 直接拿該 translation source 的 source strings 當作 training data

和原本一樣，如果執行的 translation source 是 root translation source (非 leaf) 
那要把 children (leaf) 分別執行的結果收集起來

三、調整「preview training data」和「 trigger training」的功能
原本是兩個分開的功能，合併成一個「training」功能，點擊後進入一個表單
使用者可以選擇：
- 是否 trigger jenkins job
- 是否 send data to googlesheet (for preview)
	- 一樣要輸入目標 googlesheet 位置
	- 一樣要輸入 worksheet 名稱(或使用預設值)

兩者至少要選一種才能執行

實際運作的流程也會調整成像是：
- 先生成 training data
- 若有勾選 send data -> 執行將資料傳送到 google sheet 
- 若有勾選 trigger jenkins job -> 將資料上傳到 cloud storage -> 再呼叫 jenkins job

因為生成 training data 的 effort 變重了 (有可能涉及 rebuild formatted string)，
所以要拆出來處理，將得到的資料可以分別用於 send to google sheet 和 trigger jenkins job

以上是修改的需求，請詳細評估並規劃實作內容，
若有任何建議或問題請提出


## 實作 Rebuild Segmentation (formatted string) 的功能

一、在 admin/translation_sources/:id 加上
放在 Training Preview 前面，按下後跳出 confirm 確認後再執行
前提該 translation source 必須要有 segmentation rules，才會出現「rebuild segmentation」的功能

二、實作 Segmentations.rebuild(project, translation_source)
- 檢查 translation source 必定要有 segmentation rules
- 清除該 translation source 下的所有 source strings 的 child `source_string_references` 
	- 只刪除 reference，不刪 related source string 資料
- 清除所有 segmentation rule 所衍生的 translation sources 下的 formatted source strings (包括 translations)
- 重新執行 segmentation (Segmentations.process_segmentation) 讓它 upsert child source string (及重建 reference)
- 重新執行 Patterns. process_n1_pattern_formations 來重建 formatted source strings 與 translations

以 TranslationSource: namespace= passive_skill_sets, property = itemized_description 為例
系統中有兩條 segmentation rules，會衍生出兩個 derived translation sources:
- namespace = passive_skill_sets, property = itemized_description.condition
- namespace = passive_skill_sets, property = itemized_description.effect

會將這兩個 derived translation sources 下的 formatted_source_strings(包括 translations) 清除重新生成



Trainings 
需先判斷 TranslationSource
- 沒有 segmentation rules
- 直接拿 source string + purpose has training 的資料來 build data
- 若有 segmentation rules
	- 用各 rules 取得 derived translation source
	- 從 parent source strings 取得 child source strings
