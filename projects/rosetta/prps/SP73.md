我要用當前專案的 repo 來備份我的環境設定

以下為做管理的環境設定清單與對應當前專案的路徑：

| 分類     | 環境位置                   | 專案位置                   |
| ------ | ---------------------- | ---------------------- |
| claude | $HOME/.claude/settings | ./claude/settings.json |
| claude | $HOME/.claude/skills   | ./claude/skills        |
| zsh    | $HOME/.zshrc           | ./zsh/zshrc            |
| zsh    | $HOME/.zsh-functions   | ./zsh/functions.zsh    |
| neovim | $HOME/.config/nvim     | ./nvim                 |
| btop   | $HOME/.config/btop     | ./btop                 |
| ssh    | $HOME/.ssh/config.d/   | ./ssh/config           |

可以執行的管理操作包括

1、備份
會將當下環境的檔案/目錄，複製到當前專案 repo 下的路徑進行備份
對每一個複製來源位置，會先檢查它是否盥真實的檔案或目錄，才進行複製
如果它是一個 alias，就略過

2、更新
可以將每個檔案，從專案位置，更新到當下環境對應的位置
可以用參數控制更新是用「檔案複製」(--copy) 或「--alias」的方式，預設用 copy

3、可以單指定備份或更新特定的分類
可以用參數來指定要更新或環境的分類
例如 --category claude,zsh
預設是全部 (--all)

4、備份或更新的動作
在執行前都會先進行預覽，列出要執行的細節
並輸入 yes 確認後才真的執行

5、分類、環境位置、專案位置的整份清單要可以後續維護管理

預期可能執行的指令會像是：

ex:
```
myenv.sh copy  # 預設就是 --all
myenv.sh copy --all
myenv.sh copy --category claude,zsh
myenv.sh update  # 預設就是 --all + --copy
myenv.sh update --all
myenv.sh update --all --alias
myenv.sh update --category ssh,btop
```

可能可以再加上指定 home directory
若沒有的話，預設就用 $HOME 環境變數

ex:
```
myenv.sh update --home /other/homepath 
```

也不一定要用 shell
如果有更合適的方式，做成可執行的指令也可以
