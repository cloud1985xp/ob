# 實作 Glossary Correction

目前在 model_stage 有一個 LLM 做 glossary correction 來校正翻譯的功能要實現
目標是對當前翻好的各語言 translations
再呼叫 LLM Provider (vertex AI) API ，來針對翻譯中出現的 glossaries 做校正

行為上，需搭配從 ctx.subject (TranslationSource) 所參照的 glossaries 拿到 glossary 字典
然後依原文，取出有用到的 glossaries 詞條(與翻譯)
接著將原文和目標語言翻譯，配合 glossaries 詞條，組成 prompt
請 LLM 校正翻譯中用到的 glossaries 是否有用到正確的翻譯，並將校正後的結果回傳


取得 glossaries 的方式，可以參考下列相關程式
```
Rosetta.Translations.Reviews
Rosetta.Translations.Glossaries.list_entries_for_pair
```
裡的作法

如果該 subject (TranslationSource) 沒有任何 glossaries，則略過 glossary correction 用當下已翻好的翻譯結果

目前設計預計會從 ctx.subject 在 build_correction 時拿到要用的 prompt 模版 (取得的方式之後會再另外實作，可以先寫死回傳)
prompt 模版未來會有多個語言不同的版本，但目前僅用預設的 common 版本
prompt 內容會將要來源語言名稱、目標語言名稱、來源語言的文字 + 目標語言的文字 ，以及對應的 glossaries 詞條(含原文+翻譯) 放進模版中
傳給 llm provider API 進行校正，回傳校正後的翻譯

prompt 的 common 模版先定義為：
```
You are a strict LQA validator for 'Dragon Ball Z Dokkan Battle'. Your input is a %{source_language} Source and a %{target_language} MT5 Translation.

The MT5 translation is high-quality and usually correct. Your goal is to DETECT ERRORS, NOT to rewrite or improve style.

Strict Rules:
1. **Katakana Name Check**: Strictly compare the phonetics.
   - If the characters are different in Japanese, the translation MUST be different.
2. **Numbers & Logic**: Only fix mismatched numbers, categories and effects.
3. **Do Not Polish**: If the translation is understandable and factually correct, DO NOT change a single character.

Overall Rules:
1. Mistranslation (meaning is incorrect).
2. Number not match (parameters are not the same from Japanese)
3. Over-translation (contains information not in the source).
4. Under-translation (is missing information from the source).
5. Use glossary(below) as a refference.
6. Missing or wrong symbols (like quotaion mark and space. Especially leading quotation mark is always disappearing in mt5 result. Korean should use """" instead of 「」.Half width comma should always be followed by a space.)
7. CRITICAL FORMATTING RULE: You are STRICTLY FORBIDDEN from using the backslash character ("\") anywhere in your output. Never escape brackets. Output [Case] exactly like that, NEVER as \[Case\].

Task:
- Compare the %{source_language} source with the %{target_language} translation.
- If the %{target_language} matches the %{source_language} meaning and phonetics (even if it's an obscure character), return the %{target_language} MT5 Translation exactly as is.
- Only return a corrected version if there is a critical factual error (wrong number, missing skill effect, wrong character name phonetics).In this situation, return *only* the corrected %{target_language} translation. Do not add explanations or any other text.

Input: 
%{source_language}: %{source_content}
%{target_language}: %{target_content}

Output: Only the final %{target_language} text.


Glossary:
%{glossary_pair_translations}

```

其中 
%{source_language} 代表來源語言
%{source_content} 代表來源語言文字
%{target_language} 代表目標語言
%{target_content}代表目標語言文字
而 %{glossary_pair_translations} 例如會是這種型式 (ja = zh_tw 為例)
```
良心0%の恐怖 = 毫無良心的恐怖,
ATK = ATK,
DEF = DEF,
```
