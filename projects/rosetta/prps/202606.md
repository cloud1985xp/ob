# 優化 Admin Source String 管理
即 /admin/source_strings/ (RosettaWeb.SourceStringController.index)

需要在列表同時顯示各語言內容
- 在 query source strings，同時 preload translations
- 在 list 列表時，同時列出各語言 translation content
- 在 table 外層元素，加上 overflow-x auto 讓 table 超出水平寬度時出現捲軸

## 實作 Align Translations 功能

實作在 /admin/source_strings 下
在 source_strings 列表，每個資料列前方加上 checkbox
讓使用者可以勾選想要同步的 source_strings
勾選後，點選 table 上方的的「Align Translations」按鈕後，進入 align translations 功能
- 在 table 上方加上一個 bulk selection 的 toolbar，做為對選取的目標資料列進行操作，目前只有「Align Translations」

### Align Translation 功能
路徑: /admin/source_strings/alignment
需傳入 source_string_ids 做為要對齊翻譯的 source strings

在畫面上將所有使入的 source string 列出來，放在一個表單中
類似原本的 source string index 列表，但只需要 identifier、content 與各語言 content

使用者可以依 translations 的各語言，選取要用哪一個(資料列) source string 的 content
各語言是各自的 radio input 來選取

按下表單送出後，會把各 source string 的各 translations content，都更新成被選擇的那個 content 內容
並把各 source string 的 translated 設成 true
