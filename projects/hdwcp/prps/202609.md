# 增加 Dealer Warranty Label

在 Dealer 上增加一個欄位 warranty_label, string(255)
並更新 Dealer 的 form 增加可以編輯這個欄位的內容 (text field)
- 位於 /contacts/dealers 下的 new 和 edit 裡的 form

## 實作大量更新 dealer warranty labels 的功能

在 /contacts/dealers/warranty_labels 下實作批次更新 warranty labels 的功能
在畫面中有一個 form，可以 nested 增加 rows
每個 row (fields) 代表要對哪一個 dealer 設定新的 warranty label
每增加一個 row，要設定欄位包括 dealer_id 與 warranty label
- dealer_id 用下拉選單讓使用者選擇哪位 dealer
- warranty label 讓使用者輸入想要設定的目標文字，預設為空值即可

在 form 裡可以增加或移除 row
整個 form 送出後，就會將對應的 dealer 更新成指定 warranty label

## 實作匯入 csv 更新 warranty labels 的功能

在 /contacts/dealers/warranty_labels/import 下實作此功能
讓使用者選擇一個本機 csv 檔案上傳
- 可選擇要不要忽略第一行 (略過 header)

csv 檔案的第一欄是 dealer number, 第二欄是 warranty label
上傳後就出現和 /contacts/dealers/warranty_labels 一樣的 form
依 csv 的內容帶出預先產生的 row，包括選擇到對應的 dealer，以及 csv 裡的 warranty label
使用者仍可以調整 row 的內容
然後送出執行大量更新
