## 基本元件定義

### 主選單
- 最多兩層選單
- 選單項目帶有 icon
- 有些選單項目會有動作捷徑，例如
	- 公告列表的選項，但右方有一個捷徑按鈕是直接進入「新增公告」的畫面
	- 通常是 optional，例如只有具有權限的使用者才會出現這個按鈕
	- 不具有權限者就只能進入公告列表
- 選單可被收起，收起時
	- 第一層只顯示 icon
	- 滑鼠移過選項會浮現第二層的選單，出現在第一層選項的右側

### 次要選單
版面右上角次要選單，包含：
- 個人資訊選單，顯示個人名稱，點擊展開選項
	- 登出
	- 編輯個人設定
	- 若為管理者會有 admin 後台選項
- 訊息通知，點擊展開訊息匣
	- 內有系統統知，例如
		- 背景任務完成
		- 系統統知訊息

### 頁面基本元件
UI Framework 裡各種共用基本元素也請幫我設計
可以參考 DaisyUI 有定義的各種基本元件

包括像題
- 頁面標題
- 副標題
- 麵包屑(breadcrumb)
- 一般內容卡片 (card)
- 常用元件，包括按鈕、badge/label
- 表單輸入元素


## 名片元件
以下再定義目前已知會需要的特定資源物件設計樣式的名片元件
包括呈現的資訊內容，和主要的使用行為

### 使用者名片
UserCard
資訊包括：
- 使用者名稱
- 所屬部門
- 個人圖示，若沒有圖片會用名字縮寫兩個大寫字母表示
行為：
- 點擊後前往瀏覽個人資訊
### 部署日
OperationCard
部署日卡片的內容由多層資訊組成
呈現方式以 timeline 的方式
會有多個特定的日期點

呈現資訊包括：
- 部署日本身的日期
- timeline
	- 每個日期點
		- 日期點下的多個事件(EventCard)
		- 每個 EventCard 的資訊包括：
			- 標題
			- 開始時間
			- 活動等級：S,A,B,C 可配合顏色來區分
			- 一張半透明漸層背景圖
點擊部署日會前往瀏覽該詳細內容

### 環境名片
StageCard
環境名稱：例如 Bulma, Chaozu, Beerus
目前的程式版本：例如 v5.33.4
目前的狀態：例如更新中，可以用 icon 或顏色來表示
另有一些 optional icon 來表示：竟如 上鎖的圖示

使用情境：
- 一般資訊呈現，點擊環境名片會前往瀏覽其詳細內容
- 作為下拉選單的選項，點擊後會 refresh 當前頁面
## 選單元件

### 頁面動作選單
對當前頁面對象資源(例如正在瀏覽公告) 的操作動作選單，
動作例如：編輯、下載、複製、匯出…等

請為這個元件定義一個公用的樣式，以及設定它會出現在面版的位置

### 列項目動作選單
在表格內單列項目資源的動作選單
例如瀏覽使用者名單，每一列使用者資料，通常置於最後一欄對其操作的動作選單，例如編輯、刪除、瀏覽，同時可以有可展開的次選單。

### 大量操作動作選單
在表格或清單中勾選多個項目，對選擇的項目整批進行 xxx 操作的選單

### 語言選單
系統在某些畫面會有「同時顯示多個語言對照內容」的情境
這時使用者可以自訂一次要顯示哪幾種語言
- 總共會有6個語言
- 每個語言都用 locale code 顯示，例如 EN, FR, KO
- 每個語言選項都是 on/off 的開關行為，例如
	- 點擊 EN 將 en 打開，再點擊 FR，表示同時啟用 EN, FR，再點擊 EN 會關閉只剩下 FR
- 當點擊任一個語言 on/off 就會直接 refresh 當前頁面

請為這個元件定義一個公用的樣式，以及設定它會出現在面版的位置

### 環境選單
為讓使用者切換當前 Stage 的選單，點擊會浮現下拉選單，選項會是環境卡片
收起時只會顯示 stage 名稱，請設計成行內元素
要可以被作為麵包屑元件中的一個路徑項目
