
# 重新設計介面與視覺
我想為專案重新設計視覺與 UI、操作體驗
可以搭配 claude design 或你任何建議、可使用的 design 相關 skill 來進行設計

我原計畫你以下面的需求，產生一份我可以上傳到 claude design 使用的資料請它進行設計
但我不確定現在有沒有更好的方法來完成，你可以建議作法

請先釐清並理解產品範圍和定位，來重新設計 UI
產品主要定位是一款簽核流程的 SaaS 服務
主要分成三大部分
1. SaaS 平台基礎，像組織、公司、成員、部門等管理
2. 表單系統，自訂表單、表單填寫、依表單將資料寫入資料庫，後續瀏覽或統計資料
3. 流程管理系統，自訂各種流程，並為每個流程整合表單系統與組織架構進行簽核

請依常見的類似產品，以及現代化的使用體驗，結合創意、美學、友善操作等，來為這項產品重新設計頁面，包括配色標準、頁面版型、互動元件設計等，以及後續各個功能的頁面細節

有幾點原則與需求
- 需有適應手機操作的版型
	- 除了設定類的頁面，例如編輯表單設定、編輯流程
	- 使用者在跑流程、填寫表單內容時，要支援手機操作
- 請以產品定位與使用目標為前提，如果是目前功能不支或/未實現，但你覺得是必須的設計，也請加上，並先用假資料代替，之後再實作功能
	- 例如流程圖的呈現，可以導入繪製流程圖的套件
- 實作時會基於 TailwindCSS + DaisyUI 為基底進行設計

我覺得可以分類要執行的內容，
- 整體風格與視覺：定義色系 token、各種 variant 與基本元素樣式
- 一般介面
	- 常見 ui 元件，如選單 、dropdown、property list、button…等
	- 常見表單元件
- 一般頁面
	- 登入頁
	- 個人管理
	- 基本頁面
- 後台各種設定管理功能
	- 標準的 CRUD 操作

再來是比較為這個專案設計的內容、元件
需要詳細理解專案的功能，制訂設計規格
這部分我覺得可以分段進行

一、使用流程操作
- 使用者要一目瞭然知道流程的狀態、下一步要做什麼
	- 可以設計 Card 物件，放在 總覽頁(dashboard)
	- 包括主流程(理解目的)下的各個子流程(理解進度)狀態
		- 已完成的流程可以收合/簡化
- 瀏覽流程的內容，能知道主流程為何，目前正在哪一步，以下上/下遊的關係
	- 

二、表單填寫
- 主要依賴一般表單元件
- 但有一些特殊欄位，可以加強設計
	- 例如航班出發/到達時間，可以有更具像化的圖示來美化欄位

三、後台的表單編輯器
- 比較複雜，可以先理解，之後再討論設計
四、後台的流程編輯器
- 比較複雜，可以先理解，之後再討論設計
