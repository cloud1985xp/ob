Slack Digger

請用 skill creator
我想建立一個 skill，會用 slack 進行多種行為：

一種行為是「探尋答案」
使用情境在 agent 跟我合作開發遇到一些問題或疑問時，問題的答案可能會在 slack 的討論串上，這時我會呼叫這個 skill 並給定一個 slack link 要 agent 透過 api 去查找這串 tread 的討論內容，理解後推導出問題的答案

如果理解後仍無法得到答案會有進一步的問題要詢問，agent 就會再回覆到 thread 繼續提問
並設定輪詢看有沒有得到回覆，得到回覆就再次推論是否得到解案

若判定有解答了，就繼續手邊任務
若沒有答案，就再次提出疑問到 slack thread 中，重複循環

thread 沒有更新的回覆會進行輪詢
而輪詢時間會有次數上限，每一次等候的時間就延長
如果超過輪詢次數都沒有得到回覆
agent 會發訊息到 thread 中告知已暫時追蹤這個 thread

另一個行為是「察覺需求」
我可以主動執行這個 skill 或是設定排程執行這個 skill
agent 會呼叫 api 到我預設的頻道(可多個頻道)，瀏覽最近的訊息，看有沒有內文是在討論系統問題或需求的

- 若討論是有關系統行為確認的，可以初步調查 master branch 的程式碼內容來調查問題，回覆到 thread 中

有可能會有漏抓的情況(沒判讀到問題/需求)
這時候我希望可以把 thread 連結丟給這 skill，讓它檢討為何沒有判讀到，並更新它的 knowledge / reference

此外，當 agent 執行 skill 在以下情況時，會進行彙報，將做過的事情彙整摘要傳送訊息給我(HOST)，包括

- 開始進行探尋答案
- 開始進行察覺需求
