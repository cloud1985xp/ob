Slack Digger

請用 skill creator
我想建立一個 skill，會用 slack 進行多種行為：

查找答案，使用情境在 agent 跟我合作開發遇到一些問題或疑問時，問題的答案可能會在 slack 的討論串上，這時我會呼叫這個 skill 並給定一個 slack link 要 agent 透過 api 去查找這串 tread 的討論內容，理解後推導出問題的答案

如果理解後仍無法得到答案會有進一步的問題要詢問，agent 就會再回覆到 thread 繼續提問
並設定輪詢看有沒有得到回覆，得到回覆就再次推論是否得到解案

若判定有解答了，就繼續手邊任務
若沒有答案，就再次提出疑問到 slack thread 中，重複循環

thread 沒有更新的回覆會進行輪詢
而輪詢時間會有次數上限，每一次等候的時間就延長
如果超過輪詢次數都沒有得到回覆
agent 會發訊息到 thread 中告知已暫時追蹤這個 thread，若要再
