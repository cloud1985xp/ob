# Job Description DevOps Jr.

Created: 2023年9月1日 上午10:49

在遊戲營運團隊中，Server Team 是最大的後盾
團隊內的DevOps人員，會需要同時控管上百台 Server 與百萬人以上的使用者
你將有機會和跨國團隊合作，進行營運與開發，將遊戲推向全世界！我們需要對伺服端技術有熱情又愛玩遊戲的你，

歡迎三年以上有經驗者！

【工作內容】

- 參與遊戲產品持續整合及交付
- 協助改善團隊維運流程、導入/開發自動化工具
- 透過 IaC 建置、管理遊戲伺服器的雲端服務和系統基礎設施
- 遊戲伺服器維運事件應對處理
- 監控系統與異常狀態偵測

【程式語⾔與技術】

會接觸到的技術，包括但不限於：

- Programming Skill: Ruby, Elixir, Go and Shell.
- Database System: MySQL、PostgreSQL、AWS RDS/Aurora、BigQuery
- Cloud Service: AWS, Google Cloud Platform
- DevOps / IaC: Ansible, AWS CloudFormation, Terraform
- CI / CD Tools: Jenkins, Github Action, Argo CD etc.
- Container: Docker, AWS ECS, Kubernetes
- Cache and Messaging System: Redis, Memcache, AWS SQS, Cloud PubSub, RabbitMQ
- Data/Log Collection: ELK/EFK
- Loading Test: Locust, k6
- VCS: Git/GitHub

【必備條件】

- 使用 Ruby, Elixir, Go, Python 至少其中一項程式語言，或願意學習新程式語言
- 網路技術基礎知識
- 熟悉 Mac/Linux 系統操作、開發環境，shell 指令
- 熟悉軟體開發流程、版本控制如 /[Git|GitHub](Flow)/
- 英文基本溝通能力

【加分條件】

- 具大型分散式系統、系統資訊安全技術等經驗
- CI/CD 經驗，如 Jenkins, Github Action, CircleCI 等
- 系統監控、效能分析經驗，如 DataDog, Prometheus, Grafana, NewRelic
- 微服務架構建置經驗
- 日文溝通能力
- 熱愛遊戲、對遊戲產業有興趣

【人格條件】

- Humility, Respect and Trust
- Ownership & Responsibility
- Approach Both Reactive and Proactive
- Embracing SRE Culture
- Unflappable、Thinking out of box - 臨危不亂、全局思考
- 跨職種溝通能力

- 接受風險，更懂取捨
- 接受犯錯，但校正犯錯的根本
- Share ownership & Blameless

＊應徵時可附上 Github（歡迎介紹最自豪的作品，也可提供系統架構圖或作品 demo 喔！）
