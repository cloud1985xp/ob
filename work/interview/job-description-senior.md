# Job Description Senior

Created: 2021年7月22日 下午10:01

在遊戲營運團隊中，Server Team 是最大的後盾
團隊內的DevOps人員，會需要同時控管上百台 Server 與百萬人以上的使用者
你將有機會和跨國團隊合作，進行營運與開發，將遊戲推向全世界！我們需要對伺服端技術有熱情又愛玩遊戲的你，

歡迎三年以上有經驗者！

【工作內容】

- 伺服端應用程式開發、更新，錯誤追蹤與程式碼管理
- 遊戲服務/產品持續整合及交付
- 系統基礎架構建置、管理與監控
- 負責遊戲伺服器可靠性、提高效能、維持服務水準與意外事件應對處理
- 改進產品維運流程、自動化工具開發與維護
- 遊戲日誌管理與分析
- 資料庫系統規劃與開發與維護

【程式語⾔與技術】

- Language: Ruby on Rails/Elixir, Shell Script, SQL
- Database: MySQL、PostgreSQL、AWS RDS/Aurora、BigQuery
- IaaS: AWS, Google Cloud Platform
- DevOps / IaC: Ansible, AWS CloudFormation, Terraform
- Container: Docker, AWS ECS, Kubernetes
- Cache and Messaging System: Redis, Memcache, SQS, Cloud PubSub, RabbitMQ
- Data/Log Collection: ELK/EFK
- VCS: Git/GitHub

【必備條件】

- 三年以上 Server 開發 或 DevOps 經驗
- 精通後端應用程式開發、自動化測試
- 網路技術基礎知識
- 熟悉關聯式資料庫
- 熟悉 Mac/Linux 系統操作、開發環境
- 熟悉軟體開發流程、版本控制如 /[Git|GitHub](Flow)/
- CI/CD 經驗，如 Jenkins, Github Action, CircleCI 等
- 英文溝通應對能力

【加分條件】

- 日文溝通能力
- 熟悉其他語言如 Python, Golang, Rust, Node.js, Java 之一者
- 具大型分散式系統、系統資訊安全技術等經驗
- 系統監控、效能分析經驗，如 DataDog, Prometheus, Grafana, NewRelic
- 微服務架構建置經驗
- 具資料分析相關經驗
- 具前端開發相關技術，如 React, HTML5, VueJS 等
- 沒有遊戲業經驗亦可，但需對遊戲有興趣

【人格條件】

- Humility, Respect and Trust
- Ownership & Responsibility
- Approach Both Reactive and Proactive
- Embracing SRE Culture
- Unflappable、Thinking out of box - 臨危不亂、全局思考
- 跨職種溝通能力

- 接受風險，更懂取捨
- 接受犯錯，但校正犯錯的根本
- Share ownership & Blameless
