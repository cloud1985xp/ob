# Workspace

Created: 2019年11月8日 下午4:41

R 60, B 60+, Y 79

mViolet [38 - 48]

核心目標

這種菜鳥底子都不會太紮實，主要看有沒有救不回的壞習觀

基本程式開發能力

能自行理解並獨立完成 SP < 8 的任務

- 簡單的 bugfix，找到錯誤點，但僅是幾行程式碼的修正
- 基本的 CRUD 程式
- 現有的 gem 的使用或常見(易找到範例)服務的串接

能撰寫 RSpec，但未熟悉，無法快速產出

Code Review

- 僅能進行語法、邏輯偵錯
- 未能對他人的程式提出改寫或重構建議

Git / 協作開發

- Git 基本指令操作

Indigo [41 - 60]

- 需具能力處理 Story Point > 8 的任務，具備將超過 SP 13 的 task 規劃切割的能力
- 能正確地依序 Best Practice 開發 Rails，並有效率地完成 RSpec
- 開發過程中能顧及團隊協作性與可維護性
- 能正確使用 Git
    - 正確地 Commit 的割分習慣、branch 管理、cp、patch
    - merge/reset/checkout 結合參數運用
    - Rebase

- 能進行並有意識地管理部署、產品發佈

Blue 48 - 85

- 能依照需求進行完整/全新的功能開發，進行規劃開發計畫與任務

Green 65 - 130

- 能找出問題轉化
