# Uncle Bob（Robert C. Martin）

軟體工程師、作家、講師，以 Clean Code、SOLID 原則和 Clean Architecture 聞名。

## 主要貢獻

- **Clean Architecture**（2012 年）：整合 Hexagonal、Onion、EBI 架構，提出統一的分層架構模型
- **SOLID 原則**：單一職責、開放封閉、里氏替換、介面隔離、**依賴反轉**
- **Clean Code**：乾淨程式碼的最佳實踐書籍

## 對 Clean Architecture 的評價

Clean Architecture 並非革命性新概念，而是整合既有智慧的重要整理工作——類比：Robert C. Martin 是軟體開發界的 Isaac Newton（重力一直存在，Newton 只是把它明確化了）。
