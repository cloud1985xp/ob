# 排程自動化（Loop & Schedule）

[[Claude Code]] 內建的定時自動執行機制，[[Boris Cherny]] 稱之為「Claude Code 最強功能之一」。

## 指令

- **`/loop <間隔> <指令>`**：以固定間隔重複執行某個 slash command
- **`/schedule`**：排程一次性或定期任務，最長可排程一週

## Cherny 的實際 Loop 範例

```
/loop 5m /babysit
```
每 5 分鐘執行一次，自動處理 code review 回饋與 PR rebase。

```
/loop 30m /slack-feedback
```
每 30 分鐘自動將 Slack 上的使用者回饋整理成 PR。

## 設計哲學

> 「把工作流打包成 loop 的思維，是 Claude Code 最值得深度探索的方向之一。」— [[Boris Cherny]]

這讓 Claude 在完全無人監管的狀態下持續推進任務成為可能，配合 [[Hooks 機制]] 中的 `Stop` hook（自動戳 Claude 繼續執行），幾乎可以實現零人工干預的持續工作流。

## 與 Hooks 的協同

- `Stop` hook：Claude 停下來等待時自動繼續，讓 loop 不中斷
- `SessionStart` hook：每次 loop 啟動時自動載入最新上下文
