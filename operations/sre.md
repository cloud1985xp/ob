# SRE

- 面對維運為主的工作內容，我們追求在穩定的前提下(效能)，工作的更有效率
- 在`企業方針`下：最近這一到兩年的時間，事業不會有太大的改變，停滯期下我們可以怎麼好好利用這段時間
    - 能力的成長
    - 為未來做好準備
    - 開拓新的道路
- 在`專案現狀的框架`下，我們受限於一些政策/流程的限制，不太能完整將技術成長與例行工作整合，兩者之間要如何取得平衡
- 分工與合作

    - 團隊合作默契、分配
    - Pair Programming
    - On Call
- 薪酬與制度
