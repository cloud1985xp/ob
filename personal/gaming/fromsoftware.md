# FromSoftware

Created: 2023年4月7日 下午1:21

一開始是一家軟體開發公司，商用軟體

90年代日本經濟泡沫，很多企業受到影響

因為成員都喜歡玩遊戲，利用閒暇時間做3D機器人遊戲

決定朝

機戰傭兵、國王密令，黑暗風格、高難度

PS1/PS2 時代，但沒有真的大賣的 IP

2004 年宮崎英高加入

本來也是 Oracel 的客服經理，後來在朋友的推薦下玩了一款熱愛的遊戲

決定想當製作人，當時已29歲，普遍公司沒有要

但FS接受它

負責機戰傭兵續作，但褒貶不一，想要打造自己的 ip
